## Instrucciones para Claude Design

1. Lee primero `manifest.json`: contiene perfil, textos, y para cada proyecto su `hero`, `renders` y `planos` con ruta relativa, dimensiones y texto alternativo (`alt`).
2. Usa las rutas relativas tal cual (`01_residencial/01_casa-marazul/render/01_piscina-fachada.jpg`). No renombres ni muevas archivos.
3. En cada tarjeta de proyecto usa el `hero` como portada; `renders` en orden numérico para la galería; `planos` como sección técnica aparte (fondo blanco, dibujo lineal).
4. `00_global/` son fondos y divisores del PDF original: úsalos solo como decoración. Los divisores `comercial-local-nombre` y `financiero-recepcion-nombre` tienen el texto placeholder "NOMBRE"; `cierre/conclusion-...` trae texto horneado en la imagen.
5. `00_perfil/laura-navas_retrato.png` tiene fondo transparente (PNG con alfa).
6. Textos de bio, educación, competencias y descripción de cada proyecto están en el manifest (copiados del PDF).
